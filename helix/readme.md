# Personal Helix editor configuration

## Prerequisites
1. [Helix editor](https://docs.helix-editor.com/install.html)
2. [Marksman](https://github.com/artempyanykh/marksman)
3. [harper-ls](https://writewithharper.com/docs/integrations/language-server)
4. [Markdown-oxide](https://github.com/Feel-ix-343/markdown-oxide)
5. [R language server](https://cran.r-project.org/web/packages/languageserver/index.html)

## Config
The helix config is set up for use with R programming and Markdown writing. I have made a few adjustments to keybindings to avoid conflicts in motor memory from vim, but does not try to vim-ify the keybindings. For example, x and d so that dx can delete a whole line, x deletes a character, and wx deletes a word.
